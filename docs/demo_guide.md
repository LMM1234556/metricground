# MetricGround 五分钟交付演示

## 演示目标

向面试官说明：项目价值不只是聊天界面，而是让大模型在受控范围内理解业务问题，并把结论绑定到真实数据、固定指标口径和可检查证据。

## 演示前准备

1. 在 `frontend` 目录运行 `npm run dev`；
2. 准备 `evaluation/fixtures/orders_quality_sample.csv`；
3. 浏览器打开 `http://localhost:5173/` 并切换到“新手引导”；
4. 不要提前清洗数据，让面试官看到系统如何处理风险。

## 演示顺序

1. **上传陌生 CSV**：展示系统读取行列、字段类型、候选粒度和样例，不向模型发送原始数据行。
2. **检查质量**：逐项查看重复、缺失、无效日期和异常金额。选择“暂不处理”时强调它只记录风险，不代表风险消失。
3. **确认指标口径**：选择“去重订单量”，展示模板只预填，不会替用户勾选确认，也不会提前执行。
4. **受控计算**：生成合同后进入执行页，说明自然语言不能直接拼成任意 SQL；批准后得到确定性计算结果。
5. **独立验证**：打开 TaskRun，展示 DuckDB-WASM 独立 SQL 复核、参与行数、去重对象和质量相关性。
6. **交付证据**：下载分析报告和审计 JSON，说明证据包不含原始明细行。

如时间允许，再演示两条失败路径：

- 上传关联表，故意选择 N:N 键，展示执行被阻止；
- 输入未支持的退款预测问题，展示系统澄清或拒答，而不是返回无关的 Olist 默认答案。

## 面试中的一句话介绍

MetricGround 是面向 Excel/CSV 初级分析师的可信经营分析 Agent：模型负责理解和规划，白名单程序负责确定性计算，用户确认业务口径，DuckDB 独立复算关键结果，最终保留可追溯的 TaskRun 和交付证据。

## 不应夸大的部分

- 当前覆盖通用 CSV/XLSX 的基础画像、质量、指标、分组、趋势、Top N 和最多三表关联，但不是任意自然语言分析；
- TaskRun 已持久化并支持条件式账号隔离，但外部数据库连接、角色权限和团队空间仍未实现；
- 30 题结果是自建回归题集，不是权威基准；
- 项目所有者手工走通 3 份合成文件不等于 3 名真实新人通过测试；
- 延迟配送与负面评价是关联关系，不是随机实验得到的因果结论。
