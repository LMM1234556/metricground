# MetricGround v0.3.6

本轮来自真实交付文件检查：数值与样例复算一致，但 Markdown 没有显示 AnalysisSpec，JSON 的复核 SQL 被 500 字符规则截断，风险和模型来源只存在界面/接口而未进入任务证据。

## 改动

- 完整保存实际 DuckDB SQL 和绑定参数，不用模型重新生成查询。
- 新任务保存规划来源与已知 Token 用量、风险明细和判断快照、基础检查及独立复核、结构化聚合结果。
- 报告输出完整口径与复核明细；未记录的历史字段明确缺失，不推断企业收入、利润或币种。
- 修复已完成任务残留“执行前确认”提示。
- 格式 1.1 保留旧任务兼容；原始数据行不进入证据包。筛选值/分组名属于业务信息，分享前仍需检查。

## 验收与边界

详见 [本轮验收记录](../../evaluation/evidence-export-v0.3.6-2026-10-10.md)。本轮测试不新增付费模型请求，也不改变公开访问、累计二十次请求限制和原始文件保护。

历史 JSON 已被截断的 SQL 不能凭空恢复；如果同浏览器 TaskRun 仍保留完整查询，可重新导出。新任务才能自动保存新增规划/风险字段；仅更新模板不能补齐过去从未记录的信息。校验码只检查文件一致性，不是第三方审计或正确性证明。
