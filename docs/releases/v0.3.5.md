# MetricGround v0.3.5

发布日期：2026-10-10。Sites 版本 9，环境修订 6，受限云模型试验已启用。

- 修复真实 Worker 中 redirect:error 导致的云请求失败；使用 manual 并拒绝 3xx，不跟随重定向或转发密钥。
- 新增真实 Worker 合成上游回归，补齐 Node 测试未发现的运行时差异；完整 CI 通过。
- 增加只读累计请求与已知用量摘要；健康状态 configured 只代表配置，并非付费模型健康探测或回答准确。
- 公网一个自建规划探针返回 cloud-agent / qwen-plus / 2步，并停在澄清态；D1 计数从1增至3，检查时剩17次，没有清空旧失败计数。

全站试验上限仍为二十次实际云 HTTP 请求，每问题最多两次，512输出 Token，24KB输入，自动重试关闭。规则回归和匿名隔离保持通过，网页人工批准/计算/下载的本轮云模型完整链路尚待用户操作验收。

详见 [公网试验记录](../../evaluation/public-cloud-trial-v0.3.5-2026-10-10.md)。不宣称任意自然语言准确率、零费用或生产 SLA。
