# MetricGround v0.3.2

发布日期：2026-10-10

公开新人测试环境：<https://metricground.chirpyseed1.chatgpt.site>

本版本减少新人测试的登录门槛，使用每浏览器独立匿名会话隔离 TaskRun。质量判断、指标合同、人工批准、确定性主计算及 DuckDB 独立复核仍然生效。

## 已验证变化

- Sites 版本 6 发布成功，环境修订为 2；版本 5 为同日初始匿名版。
- 未登录 `/api/session` 返回 `authenticated=false, required=false, anonymous=true`；HTTPS Cookie 含 HttpOnly、SameSite=Lax、Secure。
- 未初始化会话的核心 API 返回 401；合法匿名会话可规划去重订单指标，返回 200 并绑定 `order_id`。
- 两个独立匿名会话自读记录返回 200，交叉读取返回 404，跨会话覆盖返回 409 且不披露另一会话记录。
- 原有登录账号的所有者哈希保持兼容，匿名限流继续按 IP 计算。
- 拒绝请求时有上限地读取、释放请求体；限流后会话接口的首次响应已纳入硬断言。
- 显式开启匿名模式的 [完整 CI 38020033588](https://github.com/LMM1234556/metricground/actions/runs/38020033588) 静态与浏览器门禁全部通过，涵盖新人引导、桌面/移动 DuckDB、记录隔离、刷新恢复与 D1 备份恢复。

详细证据与回归状态见 [匿名上线验证](../../evaluation/anonymous-access-validation-v0.3.2-2026-10-10.md)。

## 测试结束后恢复登录

在 Sites 的运行时环境中设置 `METRICGROUND_REQUIRE_AUTH=true`、`METRICGROUND_ANONYMOUS_SESSIONS=false`，然后重新部署已保存版本。验证匿名核心 API 返回 401，登录身份能读写自己的记录。保持 Site 为 public 只代表首页公开，不能替代 API 认证配置。

匿名 Cookie 有效期 7 天。清除 Cookie、过期或恢复登录后，匿名记录不会自动迁移到账号；测试结束前下载报告。同一浏览器配置中的标签页共享匿名身份。

本版本仍是面试 MVP。线上接口通过和自动化流程通过不等同于完成 5 名真实目标用户的无指导测试。
