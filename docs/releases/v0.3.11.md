# v0.3.11 — 目标一致性保护与恢复入口

2026-10-13。基于五份v0.3.10反馈做安全优先修复，不改写历史失败证据。

## 本版本范围

- 在经营分析计划、单指标计划、TaskRun审批/启动/完成阶段，检查已明确的原问题与实际计算方式。成功率不得被金额合计替代；整体去重计数不得无提示变成客户分组；订单统计对象不能是状态类别。
- 原问题明确要求原始文件时，清洗后的范围确认不能直接覆盖原目标；必须恢复原数据，或开始新分析明确改范围。
- 在跨页可见的清洗范围提示旁提供恢复按钮。恢复后清空旧审批、合同、经营分析草案和下载标记，保持原问题与规划来源。
- 修复手动合同进入计算时问题被指标名称替换：手动业务描述、任务问题与最终口径保持同一问题，不能因名称替换绕过或误触一致性保护。
- 增加join候选类型和关联向导入口，传递最多两张关联表的字段画像并把其版本纳入关联任务证据。此动作仅承接现有人工确认向导，不自动选键、执行关联或声明关联完成。
- 分组比例/成功率仍未实现。本版本明确标记不支持，并在手动经营分析路径禁止替代计算；不宣称分组比例能力已补齐。

## 验证

新增test:goal-safety，扩充test:intent:api至18个固定场景，加入CI静态门禁；既有浏览器交接脚本增加恢复入口、原范围警告和分组比例阻止执行断言。固定场景回归不等于用户复测或自然语言准确率。

本地已通过类型检查、框架构建、核心/意图/质量相关性/经营分析/Agent基础/目录/关联/运行时/规划来源/清洗交接/证据/供应商/模型预算与workerd/提醒策略检查，及实际API、任务持久化与匿名隔离检查。没有真实模型请求。

本地自动浏览器启动被环境策略拦截，应用预览入口也不可用；浏览器操作尚未在本机验证，不把构建或源代码检查写成UI通过。发布状态和云端CI以实际结果为准，不预写成功。

## 尚未覆盖

保护只针对可识别的明确目标，不提供任意自然语言语义等价判定。分组比例、关联自主执行、多轮意图保持和企业陌生数据泛化均不由本版本证明。
