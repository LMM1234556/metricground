# MetricGround v0.3.4

发布日期：2026-10-10。Sites 版本 8 已部署到 https://metricground.chirpyseed1.chatgpt.site；公开云模型调用仍关闭。

本版在实际出站请求位置增加云模型试验保护：全站 D1 累计最多二十次请求，每问题两次，每次输出最多 512 Token，输入请求最多 24KB，关闭自动重试与思考。只允许北京地域的 `qwen-plus`，数据库失败时不调用模型。请求摘要保存用量和状态，不保存密钥或供应商原始错误。

抽取共享规划 Agent，明确开放探索、分组比较和缺字段的边界；用用户授权凭证完成三个自建真实云模型工具层探针，共六次请求、3,674 Token。它不等同于盲测准确率或公网模型端到端验收。

完整静态/浏览器 CI、SQL/fetch 控费回归、十个线上规则探针和匿名隔离复测通过。证据与重跑边界见 [验证记录](../../evaluation/model-cost-trial-v0.3.4-2026-10-10.md)。

下一步是受限公网模型测试，不是直接全面开放。二十次为 HTTP 请求上限，不是人民币硬上限；用户控制台的免费额度用完即停保护仍需保留。
