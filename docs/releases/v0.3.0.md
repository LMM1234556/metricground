# MetricGround v0.3.0

发布日期：2026-10-08

## 版本目标

在 v0.2.0 的可恢复 TaskRun 基础上，补齐可部署 MVP 的最小安全、可观测和恢复闭环。该版本仍是面试演示与小规模验证版本，不代表企业生产就绪。

## 已完成

- D1 固定窗口 API 限流，返回剩余配额、重置时间和 `Retry-After`；
- 同源写入校验、JSON 请求体上限、静态安全响应头；
- CSV/XLSX 容器、空字节、行列规模边界；
- Sites 受信身份头下的 TaskRun 所有者绑定与跨用户隔离；
- 可选强制登录及页面登录提示；
- 请求 ID、结构化 API 日志、Web/D1/可选模型健康状态；
- D1 导出、SHA-256 清单、隔离恢复和关键表数量核对；
- API 安全、上传边界、恢复演练进入自动化门禁。

## 验证结果

- `npm run test:ci:static`：通过；
- `npm run test:ci:browser`：通过；
- 通用工作台：30/30；
- D1 恢复演练：TaskRun、幂等写入、所有者绑定数量一致；
- API：错误 trace 与跨用户读取返回 404，跨站写入 403，过大载荷 413，超频请求 429；
- 浏览器流程：质量、清洗、指标、计算、多表/三表关联、新手引导和刷新恢复均通过，未发现运行时异常。

详细证据见 `evaluation/release-validation-v0.3.0-2026-10-08.md`。

## 已知限制

1. 强制身份认证依赖托管平台清除伪造头并注入 Sites 用户身份，本地只验证协议与隔离逻辑；
2. 没有 GitHub 远程 CI 成功记录、公开部署地址、远程 D1 灾备或集中告警；
3. 原始上传文件仍只在当前浏览器保存，跨设备恢复需要重新上传；
4. 限流适合小规模演示，不能替代企业级 WAF、配额和滥用检测；
5. 尚无正式目标用户研究，自动化通过不能证明新人一定会用。

v0.4.0 聚焦外部证据：远程仓库与 CI、受保护演示部署、线上登录/D1/健康检查、最小告警，以及 3—5 名目标用户无指导测试。
