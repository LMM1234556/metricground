# MetricGround v0.3.3

发布日期：2026-10-10。公开新人测试入口：https://metricground.chirpyseed1.chatgpt.site。

Sites 版本 7 已发布，保留免登录匿名隔离。本轮完成意图路由与澄清保护修复，未启用在线大模型。

## 用户可见变化

- 支持部分口语化订单去重计数，避免必须复制固定模板。
- 金额排名澄清后仍为排名任务，不跳到单指标；最大/最小默认 Top 1。
- 缺少客户、渠道、cost/price 等要求字段时停在待确认，不静默替代。
- 行数与订单数差异先查画像证据；关联金额放大引导到多表关联，不凭画像猜业务根因。
- 预测等不支持问题保持拒答；指标、质量和关联的人工确认门禁不变。

## 验证

完整静态/浏览器 CI 通过；24 个自建路由用例、8 组策略检查、5 组执行检查、15 个实际 API 用例以及 10 个线上匿名路由探针通过；双会话隔离复测通过。完整证据、失败记录及重跑方式见 [验证记录](../../evaluation/intent-routing-validation-v0.3.3-2026-10-10.md)。

这些检查不等同于真实模型准确率、真实新人可用性或生产 SLA。对未知表述和企业定义仍需澄清；在线模型接入及独立口语评测是下一阶段。
