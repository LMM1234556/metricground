# MetricGround v0.2.0

发布日期：2026-10-08

## 版本目标

把 v0.1.0 的内存态 TaskRun 升级为可恢复、可追踪、可检测并发覆盖的持久化执行记录，同时保持“原始上传数据不发往服务端”的隐私边界。

## 已实现

- D1 持久化 TaskRun 审计元数据、状态事件、人工确认、工具调用和验证摘要；
- IndexedDB 保存当前浏览器的完整工作区，刷新后恢复数据画像、质量判断、指标合同和 TaskRun；
- 每个 TaskRun 具有独立 `traceId` 和递增持久化修订号；
- `Idempotency-Key` 重放返回同一修订号，陈旧修订写入返回 HTTP 409；
- traceId 不匹配时不返回任务；
- `/api/health` 同时检查应用版本和 D1 可用性；
- 浏览器测试逐用例隔离持久化状态，并增加刷新恢复端到端测试。

## 已验证

- `npm run test:ci:static`：通过；
- `npm run test:ci:browser`：通过；
- 通用工作台固定任务：30/30；
- 专项合同：首次写入修订 1、幂等重放仍为 1、更新为 2、陈旧写入 409、错误 traceId 404；
- 上传数据与 TaskRun 在页面刷新后恢复，浏览器运行时异常为 0。

## 明确边界

- 目前是单用户本地/演示架构；traceId 是不透明读取凭证，不是登录认证或租户隔离；
- 原始表格记录只保存在当前浏览器 IndexedDB，D1 不保存原始数据，跨设备恢复必须重新上传；
- 尚未完成公网部署、限流、集中日志告警、备份恢复演练和正式目标用户测试；
- GitHub Actions 已配置，但本版本只核实了本地门禁，不能声称远程 CI 已通过。
