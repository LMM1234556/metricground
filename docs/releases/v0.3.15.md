# v0.3.15 — 口径相关的清洗影响提示

v0.3.13—v0.3.15集中处理5个标号场景回测暴露出的三个问题：派生关联结果刷新后不易再次查看；分组成功率会被错误替代为金额合计；清洗建议没有清楚说明它是否会改变当前指标的统计范围。

## 本轮变化

- `v0.3.13`：关联结果持久查看、分页和CSV下载；CSV公式前缀安全转义。
- `v0.3.14`：按分组计算去重对象比例，显式确认分子状态和分母范围；主计算与DuckDB-WASM独立SQL复算都保存分子、分母和百分比。
- `v0.3.15`：质量风险与候选口径关联；清洗预览同时展示行数和去重对象数变化；允许保留当前数据并撤回尚未执行的删行批准。

## 验证

- 确定性规则、实际规划API、分组比例主计算、DuckDB-WASM独立SQL、证据导出、静态页面断言、类型检查与生产构建通过。
- Sites版本19已发布。2026-10-14线上 `/api/health` 返回 `version=0.3.15`，Web与D1均为 `ok`；公开演示继续使用匿名会话。
- 5个标号场景的最终文件完成核对：去重订单计数、地区金额比较、原始范围恢复、地区送达率和一对多品类补充均得到与所选口径一致的确定性结果。

## 证据边界

- 5个标号场景是用户提供并配合操作得到的回测材料；没有独立核验参与者身份、是否全程无指导、完成时长或招募条件，不能写成“5名独立新人全部通过”。
- 计算正确不等于业务问题唯一解释正确。模糊问题仍需用户选择统计对象、范围、分组、分子和分母。
- 大模型只参与未被规则可靠覆盖的规划；数字由白名单工具计算。单条真实Qwen轨迹不能外推为自然语言准确率。
- 分组比例不支持比例趋势、比例Top N或任意聚合量之比。
- 登录与匿名体验由部署环境变量控制。本版本没有移除身份隔离；公开简历演示继续使用匿名会话与API限流。
