# MetricGround v0.1.0 基线说明

发布日期：2026-10-08

## 版本定位

这是开始使用 Git 管理后的第一个真实基线版本。它代表可用于面试演示和目标用户测试的本地 MVP，不代表生产级企业数据平台。

## 已交付范围

- 数据画像、质量检查和派生副本清洗；
- 指标口径确认与受控确定性计算；
- 分组、趋势、Top N 和最多三表关联；
- 连接基数、孤儿键、行数膨胀、N:N 阻断及金额对账；
- AnalysisSpec、TaskRun、人工审批、工具调用和失败状态；
- DuckDB-WASM 独立 SQL 复算及证据导出；
- 固定题集、核心逻辑测试和浏览器端到端回归。

## 发布证据

- 历史本地交付验收：`evaluation/release-acceptance-2026-09-22.md`；
- 当前能力边界：`docs/capability_matrix.md`；
- 面试演示路径：`docs/interview_walkthrough.md`；
- 本地发布验证：`evaluation/release-validation-2026-10-08.md`；
- CI 定义：`.github/workflows/ci.yml`。

历史验收结果不能替代本版本发布时的 CI。只有远程工作流实际通过后，才能对外声称 v0.1.0 的 GitHub CI 已通过。

## 已知限制

1. TaskRun 当前是浏览器内存状态，页面刷新或服务重启后无法恢复；
2. 数据库、身份认证、限流、监控和公网部署尚未接入；
3. 线上模型提供方未冻结，不能把本地 Ollama 可用性等同于云端可用性；
4. 尚未完成 3 至 5 名真实目标用户的无指导可用性测试；
5. DuckDB-WASM 默认依赖固定版本官方 CDN；完全离线模式需显式同步本地资源，生产环境后续应迁移到自有对象存储；
6. 不能保证任意复杂 Excel、任意自然语言问题和四表以上关联。

## 2026-10-08 本地基线核验

- `npm run test:ci:static`：通过；
- `npm run test:ci:browser`：通过；
- 通用工作台固定任务：30/30 通过，运行时异常 0；

- DuckDB-WASM 不再默认进入 Worker 静态资源，解除单文件 25 MiB 的部署阻断。

本地生产预览和本地门禁已经通过；GitHub Actions 尚未实际运行，因此只能声明“工作流已配置”，不能声明“远程 CI 已通过”。

## 下一版本目标

v0.2.0 聚焦一条生产闭环：持久化 TaskRun，增加幂等控制、traceId、健康检查和部署说明，并通过故障恢复测试证明任务可以恢复，而不是继续扩充分析功能。
