# MetricGround v0.3.1

发布日期：2026-10-09

## 版本目标

修复真实平板首次执行时 DuckDB-WASM 独立复核启动超时，并把这次线上失败转化为可重复的移动慢网回归。该版本是 v0.3.0 的可靠性补丁，不扩大业务分析能力范围。

## 已完成

- DuckDB Worker 与 WASM 在构建时生成同源 gzip 资源，浏览器不再默认依赖第三方 CDN；
- 支持浏览器端解压同源资源，并为不支持流式解压的环境保留固定版本 CDN 回退；
- DuckDB 初始化超时从短等待调整为 60 秒，指标执行前进行后台预热；
- 增加移动端视口、冷缓存和模拟 4G 网络的受控计算回归，并纳入 CI；
- 使用外部受邀身份在独立平板上完成上传、指标确认、主计算、DuckDB 复核、TaskRun 持久化和报告下载。

## 验证结果

- 本地生产构建和 TypeScript 检查通过；
- 桌面受控计算回归通过；
- 移动端冷缓存与模拟 4G 回归通过，DuckDB 首次复核约 9 秒完成；
- 受保护线上环境的真实平板复测通过，五项工具调用全部成功，11/11 行进入计算并完成报告下载。

详细记录见 `evaluation/mobile-external-validation-v0.3.1-2026-10-09.md`。

## 证据边界

1. 外部账号完成的是自己的 TaskRun，不等于已经人工验证跨账号读取一定被拒绝；
2. 一台平板的一次成功不能代表所有移动浏览器和网络环境；
3. 移动 4G 自动化是可重复回归条件，不是严格的实验室网络性能基准；
4. 项目仍缺集中告警、值班流程和 5 名目标用户无指导测试。

## 下一步

先完成跨账号人工越权拒绝测试，再接入最小失败告警；随后进行 5 人新人可用性测试，按真实失败点决定功能迭代。
