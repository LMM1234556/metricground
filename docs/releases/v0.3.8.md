# MetricGround v0.3.8

本轮来自一份真实 Qwen 网页任务的证据复核。旧审计 JSON 能证明 DashScope/Qwen-Plus 被调用并记录 Token 摘要，也能证明最终计算和 DuckDB 复核通过；但它没有保存人工确认前的完整候选计划，因此无法审阅模型最初选择了什么分析类型和字段。

## 改动

- TaskRun 创建时深拷贝完整候选 `AgentPlan`，后续人工修改最终口径不会倒写该快照。
- 证据格式升级到1.2；JSON和Markdown报告同时展示候选计划与最终 `AnalysisSpec`。
- 历史任务继续兼容；没有候选计划时明确显示“不能反推出模型原始字段选择”，不根据最终口径伪造历史。
- 浏览器证据测试等待文件输入完成 React 水合，避免冷启动上传事件偶发丢失。

## 验收与边界

[完整 CI 38103001675](https://github.com/LMM1234556/metricground/actions/runs/38103001675) 的静态质量门和浏览器回归均通过；公开 Sites版本12健康检查显示v0.3.8、Web/D1正常。浏览器回归实际生成报告和审计JSON，校验和一致，835字符复核SQL完整，D1持久化及刷新恢复通过。

本轮没有调用云模型，全站记录保持9/20次请求。此前真实任务只证明一次Qwen规划链路可运行，不能证明任意自然语言准确率；候选计划可追溯也不等于候选计划必然正确。
