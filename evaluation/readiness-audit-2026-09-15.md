# MetricGround Agent 就绪度审计

> **历史审计快照：** 本文结论对应 2026-09-15 版本。分组、趋势、Top N、多表关联和金额对账此后已经实现；当前状态见 [`../docs/capability_matrix.md`](../docs/capability_matrix.md)。

日期：2026-09-15

## 结论

当前版本可作为“面向 Excel/CSV 的人机协同数据质量与单指标分析 Agent”演示和试用，但尚不能宣称覆盖初级数据分析师的全部日常工作。已验证的可靠范围是数据画像、基础质量检查、人工批准的派生副本清洗、单指标口径合同、计数/金额/平均/比例的受控计算与结果校验。

## 本轮修复

- 将清晰意图改为确定性策略路由，含糊意图才调用 qwen3:8b；模型失败时安全澄清，不擅自执行。
- 修复 Agent 已选 `customer_id`、指标表单仍保留 `order_id` 的状态交接错误。
- 使用真实日历规则校验日期，阻止 `2024-02-31` 等值通过。
- 空值与非法数值不再被当作 0；平均指标只用有效数值对应的去重对象作分母。
- 数据文件、工作表、行数或字段与指标合同时不一致时阻止执行。
- 比例指标必须确认结构化分子条件与文字口径一致后才能执行。
- 修复 Excel 字段字典首行被误判为数据标题的问题，并验证多工作表切换。
- 为核心、Excel/CSV、质量、清洗、指标、计算、Agent 和跨业务测评增加可重复 npm 测试入口。

## 验证结果

- ESLint：通过。
- 生产构建：通过。
- 自动化边界与浏览器检查：71/71 通过。
- 销售订单、客户营销、库存运营三类固定任务：30/30 通过。
- 总计：101/101 项通过，无浏览器运行时异常。
- 含糊问题“帮我看看这份数据”由 qwen3:8b 完成 2 步工具调用并选择质量检查。

## 尚未完成

- 通用分组比较、时间趋势和 Top N 只有意图识别，没有确定性执行工具。
- 数据库连接尚未开放。
- 未验证复杂 Excel（合并单元格、多层表头、公式错误、隐藏表）和接近 10/20 MB 上限的大文件性能。
- 测评数据为项目自建小样本，不能证明适用于所有公司或行业。
- 当前目录没有 Git 元数据，不利于变更追踪、回滚和简历中的工程证据。

## 推荐表述

在补齐分组、趋势和 Top N 之前，项目应描述为“数据质量与单指标分析 Agent MVP”，不应描述为“通用自动化数据分析平台”。
