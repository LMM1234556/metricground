# MetricGround 线上双账号身份隔离验证记录

验证时间：2026-10-09T09:52:52.657Z

## 结论

在受保护的 Sites 线上环境中，项目所有者与一个真实外部受邀身份通过两个隔离浏览器会话执行双向 TaskRun 探针。双方均可创建并读取自己的 TaskRun，读取另一身份的 TaskRun 均返回 HTTP 404。线上 D1 的 `task_run_owners` 进一步确认两个探针绑定到不同的所有者哈希。

该结果证明当前 Sites 身份注入、TaskRun 所有者绑定与读取过滤在这两个真实身份之间形成有效隔离。它不证明角色权限、团队空间或企业级身份治理已经完成。

## 证据边界

- 只覆盖当前两个已授权身份和当前 Sites 部署版本 3；
- 404 同时隐藏“不存在”和“无权访问”，避免泄露任务是否存在；
- 尚未验证角色分级、组织变更后的权限回收、团队空间和大规模并发访问；
- 后续身份或访问策略发生变化时必须重新运行 `npm run test:hosted:isolation`。
