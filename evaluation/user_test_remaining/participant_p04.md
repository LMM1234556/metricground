# 第四位体验者：用自己的话表达业务目标

打开 https://metricground.chirpyseed1.chatgpt.site ，上传包内 Excel。请使用自己的浏览器。

团队只能优先跟进一片市场。请根据历史订单提出你认为合适的衡量方式，看看工具能否把你的业务表达变成合理的分析计划，并让你确认必要的定义。它不应把一个数字自动等同于综合经营表现。

先写下你真正想比较什么，再用自己的话提交问题。不需要使用字段名、SQL或页面推荐措辞。首次只提交一次，不通过反复改写试探系统；后续通过页面控件检查、确认并执行。你可以拒绝不符合原意的计划，不必为了完成而接受默认值。

本次最多 10 分钟。结束后下载报告和审计 JSON；若没完成，只导出当前证据即可。请附上：原问题、你原先想衡量什么、系统是否理解，以及最困惑的一步。

无需购买服务、提供账号密码或 API Key。
