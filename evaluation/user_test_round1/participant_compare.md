# MetricGround 首次体验任务

地址：https://metricground.chirpyseed1.chatgpt.site

使用包内的Excel。你需要给同事一个关于地区表现的比较结果，但同事还没说明“表现”指什么。请先看数据，再决定怎样比较才有意义，并说明你的选择和限制。

请先用自己的话写出你会向工具提出的问题，然后提交。不要照抄网页示例，也不要求你知道字段名或SQL。首次提交后先保留回答，不要反复发送；可以通过页面控件确认或修改分析方式。

操作时说明：系统有没有要求你把问题说清楚？你的比较指标是什么？退款、重复记录、缺失值和异常值会不会改变这个比较？你是否知道自己的选择会包含哪些记录？不确定时可以保留风险或停止，不需要猜出主持人期待的答案。

尝试完成你认为合适的一次比较，找到用于验证结果的证据，下载报告和审计JSON。解释结果为什么适用于你确认的口径，以及它不能说明什么。如果无法完成，请保留提示并说明最先卡在哪里。

首次不看演示、不查看答案。请使用自己的浏览器。不要为了让流程通过而勾选自己尚未理解的确认项。

结束后回答：最难理解的一步是什么？你凭什么相信或不相信结果？下次独立使用最担心什么？请将报告、JSON和反馈发给邀请你的人。
