# 首轮自由表达与新人测试

本轮从v0.3.9的真实Qwen完整链路验收进入目标用户研究。测试材料准备完成不代表参与者已完成测试。

## 本轮安排

先邀请P01、P02各一名首次接触产品的参与者，每人15—20分钟，各提交一个由自己组织语言的问题。P01完成订单规模分析，P02选择地区比较口径。P03—P05材料为后续轮次准备，当前不要同时启动。

2026-10-11准备时公开预算为已用15/20、剩余5次HTTP请求。每个需要Qwen规划的问题最多2次请求，当前最多允许两次这样的新问题完整规划；规则路线可能不消耗模型请求，但不能预先假定参与者一定命中规则。超过额度后的规则兜底必须单独标记，不能作为模型理解错误或模型成功。

软件基线：v0.3.9，Sites版本13，功能提交 `eb90c7925ccbd04148479a6534298d5eec93c371`。首轮开始到所有参与者的第一次尝试结束前，保持该版本不改路由、提示词或字段默认规则。

## 文件边界

- 参与者：仅收到自己的ZIP包，包含任务说明和分配的数据。任务只规定业务目标，不提供SQL、字段选择答案或示例问句。
- 主持人：阅读 `host_protocol.md`，使用 `host_record_template.md`记录。独立参考值由构建脚本读取既有Excel与CSV重新计算，生成在运行时目录中。
- 邀请文字：见 `invitation.md`。仅为可复制草稿，尚未发送给任何人。

既有五份Excel的原始内容保持不变。包内只包含合成测试数据，没有API Key、主持人答案或真实用户数据。

## 什么才是盲测

本文和任务目标已被开发者看到，不能将它们称为独立外部盲测题集。参与者的原始问法必须在查看系统回答之前记录；这些未参与路由开发的表达，才可以用于本轮固定版本上的留出评估。先看回答再改写问题、开发者代写问句、边测试边修改规则，都记为探索或回归，不计入首轮盲测。

区分四类证据：已有自建回归、项目所有者冒烟测试、首次参与者独立尝试、修复后回测。修复回测可以证明迭代有效，不能回填首次成功率。

本轮复用已知合成数据，只评估首次表达规划及后续控件流程；不据此宣称企业陌生数据泛化或多轮自由追问能力。

## 构建与交付

在仓库根目录使用安装了openpyxl的Python运行 `scripts/build_user_test_round1.py`（本机使用Codex附带的Python）。它只读取既有Excel/CSV，核对参考结果、创建参与者ZIP和主持人参考JSON，不请求模型，也不重写Excel。脚本不会覆盖已存在的输出目录；新一轮请修改输出目录名并保留旧包。

五个包准备齐全不意味着五人测试已经获准同时消耗当前有限模型额度。第一轮先用两个包，其余包在核对剩余额度并另行安排后使用。
