# MetricGround 首次体验任务

地址：https://metricground.chirpyseed1.chatgpt.site

包内提供订单、商品明细两份CSV和一份备用Excel。本轮先使用两份CSV。你想把商品品类补到订单信息中，同时保持订单数量和订单金额的业务含义。

先用自己的话提出一个问题，再尝试使用工具完成关联与核对。不要照抄页面示例，不要求你手写SQL。首次提交后保存回答，不反复发送；通过页面控件继续操作。

请判断关联会不会改变一行代表什么、金额是否仍能直接相加、未匹配记录如何处理。如果工具提示不安全，找出证据并解释为什么不能继续。安全阻断并正确解释也是有效完成，不要求强行得到数字。

结束后将当前证据或报告、审计JSON和最困惑的一步发给邀请你的人。首次不看演示、不查看答案，请使用自己的浏览器。
