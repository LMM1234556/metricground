# MetricGround v0.1.0 本地发布验证

验证日期：2026-10-08

## 结论

本地发布门禁通过，可以作为 `v0.1.0` 的面试演示与目标用户测试基线。该结论只覆盖本文件列出的代码版本、运行环境和自动化场景；不能替代真实用户测试，也不能表述为 GitHub Actions 已通过。

## 运行环境

- 操作系统：Windows 11；
- 本地 Node.js：24.19.0（项目要求 `>=22.13.0`，CI 配置固定为 22.13.0）；
- 浏览器：Microsoft Edge 154.0.4258.48，无头模式，CDP 端口 9224；
- 应用入口：Wrangler 生产构建本地预览，`http://localhost:5173/`；
- 独立复核引擎：DuckDB-WASM 1.32.0。

## 关键可验证结果

- 清洗回归确认原始文件哈希前后一致，只生成派生副本；
- 指标和经营分析同时通过主计算基础校验与 DuckDB 独立 SQL 复算；
- 独立复核比较指标值、参与行、去重对象、排除记录、比例边界或分组结果；
- N:N 关联被阻止，连接膨胀、孤儿键和金额不守恒风险可见；
- 三表关联按两步关系确认执行，最终结果继续进入画像和分析；
- 5 份新人测试文件均能读取并展示字段画像；
- 整套浏览器回归未捕获运行时异常。

## 本次修复的发布阻断

1. DuckDB 的 33–38 MiB WASM 不再默认打入 Worker 静态资产，解除 Cloudflare Workers 单文件 25 MiB 限制；默认加载固定依赖版本的官方 CDN，离线环境可显式同步本地资源。
2. 浏览器专用 DuckDB Worker 改为动态加载，生产入口首屏由 HTTP 500 恢复为 HTTP 200。
3. 工作台测评不再依赖固定毫秒等待：每次计算都等待合同、执行条件和 DuckDB 复核完成，并加入 120 秒失败超时与阶段日志。
4. CI 浏览器地址统一为 `localhost`，并关闭后台标签页计时器节流，避免 CDP 测试找不到目标或无限等待。
